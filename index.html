01 // IELTSUP WRITING WORKFLOW

IELTSUp — AI-assisted Writing Practice & Feedback

Production Deployment

An independent IELTS Writing practice workflow with structured AI feedback and learning-focused corrections. It does not provide official IELTS results.

ProblemStudents need actionable revisions across writing criteria, not just a single estimated band.
ArchitectureNext.js and shared TypeScript evaluation core, multi-examiner scoring workflow, Task 1 chart evidence and Firebase learning history.
EngineeringGrounded feedback annotations, model-disagreement handling, idempotent evaluation requests and refund-aware usage credits.

Code-backed architecture:
  • Task 1 evidence: Normalize structured chart inputs or inspect uploaded chart images before evaluation.
  • Examiner workflow: Run separate model evaluations and resolve large criterion-level disagreements.
  • Usage ledger: Record evaluation requests and support idempotent credit reservation and refunds.
02 // IELTSUP SPEAKING & LEARNING

IELTSUp — Speaking Studio & Learner Progress

Feature Deep Dive

Speech-enabled practice, study roadmaps and progress tools designed to help learners review their work over time.

ProblemOne-off practice sessions leave learners with little continuity or an easy way to revisit recurring weaknesses.
ArchitectureSpeech-service integration, AI topic generation, authenticated learner dashboard, vocabulary notebook and roadmap modules.
EngineeringConnected practice modules and progress history. Real-world quality, latency and scoring accuracy still require independent validation.

Feature architecture:
  • Speaking practice: Speech recognition and pronunciation-assessment integrations support learning sessions.
  • Learning continuity: Dashboard, history, vocabulary notebook and study roadmap connect practice with review.
  • Transparency: AI feedback provides educational estimates, not official IELTS examiner decisions.
